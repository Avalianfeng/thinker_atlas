# 思想者图谱

一个只读的网页外壳：把 `atlas/` 文件夹里的 Markdown 渲染成三页——展厅墙、人物页、时间线。

## 跑起来

```bash
npm install
npm run dev        # http://localhost:4321
```

## 加一个人

1. 在 `atlas/` 下新建文件夹，文件夹名就是显示名，例如 `atlas/维特根斯坦/`。
2. 往里面放任意多个 `.md` 文件，比如 `00-生平.md`。
3. 打开 `atlas/_meta.md`，在 `顺序` 里加一句，在 `人物` 下补生卒年（时间线要用）：

```yaml
顺序:
  - 维特根斯坦
人物:
  维特根斯坦:
    生: 1889
    卒: 1951
    照片: 照片.jpg
```

照片放进同一个文件夹，文件名写进 `照片` 即可；不写也会自动找第一张图。

## 加一个文件

在人物的文件夹里新建 `.md` 就行，不用改任何配置。

- 文件名决定顺序：`00-`、`10-`、`20-` 这样排。
- 文件名决定小节标题，除非文件开头写了 `# 标题`。
- 图片直接放进文件夹，正文里写 `![](照片.jpg)`。

## 构建

```bash
npm run build      # 输出到 dist/，可直接 rsync 到服务器
npm run preview    # 本地看构建结果
npm test           # 读取与渲染的单元测试
```
