# Atlas 输入格式

Atlas 只读一个文件夹：仓库根目录的 `atlas/`。任何工具只要能生成这个文件夹，就能驱动本站——不需要 Atlas 的代码，也不需要和 Atlas 通信。

```
atlas/
  _meta.md          展厅顺序、生卒年、照片（助手维护）
  维特根斯坦/        一个人一个文件夹，文件夹名就是显示名
    00-生平.md
    10-著作-逻辑哲学论.md
    照片.jpg
  荣格/
    00-生平.md
```

## 人物文件夹

- 一个人一个子文件夹，**文件夹名即墙上与人页标题显示的名字**。中文、空格都可以，网址用 URL 编码后的文件夹名。
- 文件夹里的 `.md` 按**文件名排序**依次渲染成一条连续页面。`00-`、`10-` 这样的数字前缀决定顺序（按数值比较，`2-` 会排在 `10-` 前面）；没有前缀就按字典序。
- 文件名以下划线开头的（`_草稿.md`）跳过。
- 非 `.md` 的图片会原样复制到站点的 `/atlas/<文件夹>/` 下，md 里用相对路径引用即可：`![](照片.jpg)`、`![](./照片.jpg)`。
- 没有必需的 frontmatter，没有 schema，没有 ID。新建、改名、删除文件都不用改任何配置。

## 一篇 md 的标题

小节标题按这个顺序取：

1. 文件开头第一行的 `# 标题`；
2. frontmatter 里的 `title: 标题`；
3. 文件名去掉 `.md` 和开头的数字前缀（`10-著作-逻辑哲学论.md` → `著作 逻辑哲学论`）。

正文里出现的 `# 标题` 只当普通小标题渲染，不会改变小节名。

## `_meta.md`

只放三种信息，全部可选；缺了就用文件夹名与文件名兜底。

```yaml
---
顺序:
  - 维特根斯坦
  - 荣格
人物:
  维特根斯坦:
    生: 1889
    卒: 1951
    照片: 照片.jpg
  荣格:
    生: 1875
    卒: 1961
---
```

| 字段 | 位置 | 含义 |
| --- | --- | --- |
| `顺序` | 顶层 | 墙上与时间线上的先后。没列到的文件夹排在后面，按文件夹名排序。 |
| `人物.<文件夹>.生` | 每人 | 出生年，只写数字。时间线的横轴由此计算。 |
| `人物.<文件夹>.卒` | 每人 | 去世年。省略表示仍在世，时间线画到今年。 |
| `人物.<文件夹>.照片` | 每人 | 文件夹里的图片文件名。省略时自动找：先看名字里含 `portrait`/`photo`/`肖像`/`照片` 的，否则用第一张图。 |

没有 `生` 的人不出现在时间线上（不猜），墙上照常显示。

## 渲染规则

- 支持普通 Markdown 与 GFM（表格、任务列表、删除线）。
- 不认识的语法不会让构建失败：形如 `<Note ...>文字</Note>` 的大写标签会被去掉、里面的文字保留；自闭合的 `<Foo />` 整段消失；`import`/`export` 行丢掉。
- 图片一律转成灰度，两边配色都如此。

## 页面

| 路径 | 内容 |
| --- | --- |
| `/` | 展厅墙：照片（或首字）+ 名字 |
| `/people/<文件夹>/` | 这个人的所有 md 按文件名顺序 |
| `/timeline/` | 由 `_meta.md` 年份生成的静态 SVG |
