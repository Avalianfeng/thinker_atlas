# 内容格式

Atlas 是一层很薄的显示：它读 `atlas/` 文件夹里的 Markdown，渲染成三页。没有数据库、没有后台、没有编辑功能。

完整说明见 [`framework.md`](framework.md)。这里只留要点。

## 目录

```
atlas/
  _meta.md
  <人物名>/
    00-生平.md
    10-著作-某书.md
    照片.jpg
```

- 一个人一个文件夹，文件夹名即显示名。
- 文件夹里的 `.md` 按文件名排序，渲染成一条连续页面。
- 文件名以下划线开头则跳过。
- 图片原样复制，md 里用相对路径引用。

## 标题

开头的 `# 标题` > frontmatter 的 `title:` > 文件名（去掉数字前缀）。

## `_meta.md`

```yaml
---
顺序: [维特根斯坦, 荣格]
人物:
  维特根斯坦: { 生: 1889, 卒: 1951, 照片: 照片.jpg }
---
```

只有顺序、生卒年、照片三项。缺了就用文件夹名与文件名兜底，不会报错。

## 降级

不认识的语法不会让构建失败。大写标签会被去掉、文字保留；`import`/`export` 行丢掉。写坏了的内容照样出页面。
